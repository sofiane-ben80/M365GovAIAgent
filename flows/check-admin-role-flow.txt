================================================================================
  POWER AUTOMATE FLOW CONTRACT — Governor365 - Child - Verify Admin
  Purpose: Verify the signed-in caller against an active GovernanceAdmin role
           assignment in Dataverse. Routing to the Admin Agent is never
           authorization.
  Trigger: Child flow or Copilot Studio tool
================================================================================

INPUTS

  callerUPN Text, required; bind to signed-in system context

OUTPUTS

  success       Boolean
  isAdmin       Boolean
  status        Text
  correlationId Text
  message       Text

CONFIGURATION

- Dataverse connection reference: least-privilege read access to Governance
  Role Assignment
- Microsoft 365 Users or approved Entra connector: resolve the system-provided
  signed-in identity to its immutable Entra object ID
- Optional Governance Admin Group ID: migration/reconciliation input only; it
  is not the runtime authorization source

Do not put client secrets, tenant IDs, group IDs, URLs, or connection IDs in
flow actions. Credentials belong to the governed connection.

FLOW STEPS

1. Validate callerUPN, normalize it with toLower(trim(...)), and create a
   correlation GUID.
2. Resolve the signed-in user through the approved Entra connector operation
   and retain the immutable object ID. Do not authorize by a model-provided UPN.
3. Query Governance Role Assignment server-side for that exact object ID,
   Role = GovernanceAdmin, Is Active = true, Valid From empty or not later than
   now, and Valid Until empty or later than now.
4. Return success=true, isAdmin=true only when exactly one valid assignment is
   found. Zero rows denies access. Duplicate rows fail closed as a data
   integrity error.
5. Catch failed, timed-out, and skipped connector/Dataverse actions. Return
   success=false, isAdmin=false, status=VERIFICATION_FAILED, and the correlation
   ID. Never treat verification failure as a non-error success.
6. Enable secure inputs/outputs for identity and connector actions.

ACCEPTANCE TESTS

1. Active, in-window GovernanceAdmin assignment returns
   success=true and isAdmin=true.
2. Missing assignment returns success=true and isAdmin=false.
3. Blank/malformed identity returns validation failure.
4. Inactive, future, and expired assignments return isAdmin=false.
5. Duplicate assignments and Dataverse/identity connector failure return
   success=false and isAdmin=false.
6. A changed UPN with the same resolved object ID remains authorized and the
   display UPN can be reconciled separately.
7. Agent routing and Canvas screen visibility never bypass this flow.
8. No governance SharePoint list, SQL connector, or embedded secret is used.
