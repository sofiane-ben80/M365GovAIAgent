================================================================================
  POWER AUTOMATE FLOW CONTRACT — Governor365 - Child - Verify Admin
  Purpose: Verify the signed-in caller against the configured governance admin
           Entra group. Routing to the Admin Agent is never authorization.
  Trigger: Child flow or Copilot Studio tool
================================================================================

INPUTS

  callerUPN Text, required; bind to signed-in system context

OUTPUTS

  success       Boolean
  isAdmin       Boolean
  status        Text
  correlationId Text
  message       Text

CONFIGURATION

- Governance Admin Group ID: Power Platform environment variable
- Tenant ID: Power Platform environment variable
- Graph connection: approved custom connector or HTTP with Microsoft Entra ID
  connection reference
- Required delegated/application permission: the minimum approved permission
  capable of checking membership in the configured group

Do not put client secrets, tenant IDs, group IDs, URLs, or connection IDs in
flow actions. Credentials belong to the governed connection.

FLOW STEPS

1. Validate callerUPN, normalize it with toLower(trim(...)), and create a
   correlation GUID.
2. Read the Governance Admin Group ID environment variable. If blank, fail
   closed with success=false, isAdmin=false, status=CONFIGURATION_ERROR.
3. Resolve the signed-in user through the approved Entra connector operation.
4. Check direct or transitive membership according to the organization's
   approved admin-group policy.
5. Return success=true, isAdmin=true only for a confirmed match.
6. Catch failed, timed-out, and skipped connector actions. Return
   success=false, isAdmin=false, status=VERIFICATION_FAILED, and the correlation
   ID. Never treat verification failure as a non-error success.
7. Enable secure inputs/outputs for identity and connector actions.

ACCEPTANCE TESTS

1. Known member returns success=true and isAdmin=true.
2. Known non-member returns success=true and isAdmin=false.
3. Blank/malformed identity returns validation failure.
4. Missing group configuration fails closed.
5. Connector timeout/failure returns success=false and isAdmin=false.
6. Group routing alone never bypasses this flow.
7. No governance SharePoint list, SQL connector, or embedded secret is used.
